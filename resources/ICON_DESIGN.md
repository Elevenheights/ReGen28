# ReGen28 icon refresh

Created October 15, 2026 with the built-in image-generation tool.

Master: `regen28-icon-master.png`. Production exports are generated by
`node scripts/generate-icons.mjs` (requires Sharp; optionally set
`REGEN28_IMAGE_MODULES` to a directory containing Sharp).
Existing overwritten images are preserved locally in `.icon-backups/`.

## Final generation prompt

Use case: logo-brand. Create ONE finished square mobile app icon for ReGen28,
a premium 28-day personal wellness and habit app focused on renewal and steady
progress. Original distinctive symbol: a bold flowing circular renewal ribbon
that subtly forms an R, with a single simple leaf-shaped negative-space cutout;
cohesive, not a collection of wellness clip art. Deep midnight indigo background,
luminous mint/emerald and soft lavender ribbon, restrained smooth color
transition, crisp substantial silhouette. Premium calm contemporary design,
mathematically balanced, simple enough to recognize at 32 pixels. Center symbol
occupying about 65% of canvas with ample safe margins for circular Android masks.
Full-bleed opaque square artwork all the way to edges, NO rounded outer corners
(OS provides mask), NO border or device mockup, NO text or numerals, NO tiny
details, NO sparkles, NO shadows or 3D bevels, NO watermark. Deliver the actual
production icon artwork, not a presentation sheet.

## Distribution

- iOS: opaque 1024px app icon; App Store icon comes from the new native build.
- Android: legacy, round and adaptive launcher assets, launch-screen assets,
  plus 512px RGBA Play listing export.
- App: login/register logo and favicon.
- Website: navigation logo, favicon and Apple touch icon; deploy hosting only.
- Existing store feature screenshots do not show the app icon and remain valid.

Build 4 is prepared locally. Do not replace the existing review build or submit
until fresh signing credentials and the rebuilt icon are verified.
